Fullscreen controls and feedback for watching through Moonlight.

- Tap the centre third to play/pause both videos.
- Double-tap the left/right third to seek both back/forward five seconds while preserving alignment.
- Exit fullscreen from the temporary timeline bar.
- A/S/D/G briefly display the shared playback speed.
- Shift + scroll displays Reaction A or Source B and its updated volume.
- H confirms What Did They Say? at 1×; pressing it again confirms replay ended.

Windows launch and playback checks passed, including actual mouse input over both MPV surfaces. iPad/Moonlight user testing is pending, so this release is marked beta. The tested baseline remains v0.13.0.

Download FullLengthPlayer-win-x64.zip, extract it and run FullLengthPlayer.exe with its accompanying files. Previous settings and sessions remain available. Moonlight must send taps as normal mouse clicks.
