# Full Length Player 0.14.0

Stable release of the tested dual MPV player and fullscreen controls.

- Local, Patreon/HLS and public or unlisted YouTube playback; named tracks and subtitles.
- Shared playback, speed and seeking, locked 0.05-second alignment and audio-assisted sync.
- Cropped reaction and anchored source composition; 16:9, 4:3 and 16:10 canvases.
- Saved sessions, paused loading, New session and six transparent icon choices.
- Fullscreen tap/seek controls, temporary hold speeds, volume/speed feedback and “What Did They Say?” replay.

The latest fullscreen behavior has been confirmed on the user's setup. This release consolidates it without changing playback behavior. Windows CI checks the packaged EXE before publication.

Download FullLengthPlayer-win-x64.zip, extract it and keep the files together. Run FullLengthPlayer.exe. Existing settings remain compatible. The next UI redesign will be released separately as a beta.

Audio-assisted sync works best near a shared scene and can fail under heavy commentary. YouTube availability and buffering depend on the service and network. These are not guarantees of sample-perfect synchronization.
