# Full Length Player 0.15.0-beta.1 — Compact UI

A first UI polish pass, built on the stable 0.14.0 playback engine.

- Dark charcoal interface with teal accents and clearer control grouping.
- Collapsible Setup panel with Media, Layout and Sync tabs.
- Compact shared transport and timeline beneath a larger preview.
- Session actions grouped in one menu; extra speed actions in the Speed menu.
- Existing shortcuts, fullscreen gestures, sessions, tracks and composition controls retained.

Please test setup, cropping, alignment and session restoration at your normal Windows scaling, then switch to fullscreen. The stable 0.14.0 remains available separately. Extract the ZIP into a fresh folder and keep all files together.
