# Full Length Player 0.15.0-beta.3 — Teal and orange polish

Compare this polished UI with beta.1; both downloads remain available. This build also fixes the volume-label width so the slider stays still as percentages change, and places horizontal/vertical pan together.

- Teal Reaction A and orange Source B accents, including fullscreen volume feedback.
- Slim custom sliders, visible volume percentages, clearer filenames and play/pause controls with shortcut tooltips.
- Hover/scrub timestamps on timelines. An orange band marks the shared section of the locked master timeline; hover identifies reaction-only, source-only and shared sections.
- Grouped canvas/source, crop and framing settings with separate Reset buttons. Offset nudge controls sit together.
- Matching dark URL, audio-analysis, favorite-speed and icon-picker dialogs. Session open/save dialogs remain Windows file pickers and follow Windows styling.

Existing media, synchronization, sessions, keyboard and fullscreen gesture behavior is retained. No thumbnail previews in this beta.

Extract FullLengthPlayer-win-x64.zip into a fresh folder. Try the sliders and hover times, group resets, dialogs, fullscreen volume feedback and your normal display scaling. Stable 0.14.0 and UI beta.1 remain available as comparisons/fallbacks.
