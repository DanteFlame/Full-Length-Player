# Full Length Player v0.15.0 — Compact UI, complete

Promotes user-tested beta.4 to stable with no new playback or layout behavior.

- Compact dark interface with a collapsible Media / Layout / Sync setup panel.
- Teal reaction and orange source accents, slim timelines, hover timestamps and a shared-playback overlap band.
- Grouped layout resets and matching app dialogs.
- Eight-position source anchoring: four corners and four edge centres, with vertical-only reaction anchoring.
- Anchor-aware resizing, fullscreen support and saved-session compatibility.

All beta.4 features were confirmed by the user. This stable package is also gated by Windows launch and cumulative playback/UI tests. Extract the Windows ZIP into a fresh folder; existing settings and sessions remain supported. Previous releases remain available.

Next milestone: reliability and performance, beginning with YouTube startup/buffering investigation and actionable diagnostics. This release does not change buffering settings.
