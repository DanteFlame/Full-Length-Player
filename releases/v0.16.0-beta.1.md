# Full Length Player 0.16.0-beta.1 — Streaming visibility and quality controls

This starts the reliability/performance milestone; it does not claim to fix every buffering issue.

- Open URL offers optional YouTube video-height caps: 1080p, 720p or 480p. Best available remains the default. The cap applies when opening the link, not live during playback.
- Best available separate audio is retained when offered. If no format meets the cap, try Best available; the player never silently exceeds your cap.
- Sessions remember each YouTube source's cap. Older sessions default to Best available. Direct streams and local files are unaffected.
- Session → Playback diagnostics gives an on-demand snapshot of both players: resolution, speed, buffering, approximate buffered seconds, main-stream input rate, dropped frames, resolver time and file-loaded time.
- Copy report copies only the displayed metrics. No filenames, URLs, HTTP headers or media titles are included; nothing is uploaded automatically.

Buffer estimates can be unavailable or inaccurate; input rate excludes separate YouTube audio. File-loaded time is not first-frame latency. Timing changes between opens are not a controlled benchmark.

Test the same YouTube link at Best available and 720p, compare seeking/buffering, and copy diagnostics if it stalls. Reopening replaces media and may require re-locking alignment. Check saved-session restore and local/Patreon playback as usual. Stable v0.15.0 remains the default download.
