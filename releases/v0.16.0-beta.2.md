# Full Length Player 0.16.0-beta.2 — Streaming diagnostics

Includes the new streaming controls from beta.1, with corrected spacing in the Open URL dialog found during screenshot review.

- Optional YouTube video quality limits: 1080p, 720p or 480p. Best available remains the default; limits apply when opening a video.
- Saved sessions remember the selected limit. Local files and direct streams are unchanged.
- Session → Playback diagnostics shows an on-demand snapshot of both players, including buffering, resolution, dropped frames and loading times. Copy report excludes filenames, URLs, titles and HTTP headers. Nothing is uploaded automatically.

Compare the same YouTube video at Best available and 720p, especially seeking and buffering. Copy a diagnostics snapshot if it stalls. Reopening a source may require re-locking alignment.

Buffer estimates may be unavailable or inaccurate, input rate excludes separate YouTube audio, and file-loaded time is not first-frame latency. This starts performance investigation rather than promising a buffering fix. Stable v0.15.0 remains the default download.
