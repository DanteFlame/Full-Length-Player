# Full Length Player 0.16.0-beta.3 — Streaming quality and diagnostics

First downloadable test build for milestone 16. Beta 1 and beta 2 passed playback checks but their release-publishing step failed; this build repairs draft-release lookup and includes the corrected URL-dialog spacing.

- Open URL offers YouTube video limits of 1080p, 720p or 480p. Best available remains the default. Limits apply when opening a video, not during playback.
- Saved sessions remember the chosen limit. Local files and direct streams are unaffected.
- Session → Playback diagnostics shows resolution, buffering, approximate buffer size, input rate, dropped frames and loading times. Copy report excludes filenames, media URLs, titles and HTTP headers. Nothing is uploaded automatically.

## Please test

1. Open the same YouTube link at Best available, then at 720p. Compare opening, seeking and buffering. Reopening replaces that source and may require re-locking alignment.
2. Save and restore a session with a quality limit selected.
3. Open Playback diagnostics, refresh it, and copy the report if playback stalls.
4. Confirm local/Patreon playback, sync, speed controls and fullscreen still behave as before.

Buffer estimates may be unavailable or inaccurate. Input rate excludes separate YouTube audio; file-loaded time is not first-frame latency. This is a performance-investigation beta, not a claim that buffering is solved. Stable v0.15.0 remains the default release.
