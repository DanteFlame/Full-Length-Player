# Full Length Player 0.16.0-beta.4 — Session restore follow-up

- Appearance and Playback diagnostics now live under Help beside Session, Setup and Fullscreen.
- Locked session restore performs one coordinated seek to the saved alignment instead of two back-to-back seeks.
- Network sessions allow up to two minutes per media-load/seek wait, replacing the ordinary 15-second shared-seek deadline during restore.
- Both player positions are checked before restore succeeds. Both remain paused; failed restore does not overwrite the saved session.
- Timeout messages identify the restore stage. Diagnostics include the last restore stage and whether each player is seeking.

Please retry restoring two YouTube videos (reaction 480p, source Best available), saved well into playback. Confirm both saved positions, offset, quality and speed return while paused. If it fails, copy Help → Playback diagnostics and the message. Also check an unlocked session and a local/Patreon pair.

This addresses restore-path issues found in code; it does not establish the cause of the reported YouTube buffering. Automated dual-network restore tests use local HTTP media; real YouTube behavior still needs testing. Stable v0.15.0 remains the default release.
