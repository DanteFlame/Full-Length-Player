# Full Length Player 0.16.0-beta.6 — Opposite reaction anchors

The reaction now anchors to the exact opposite source position in both axes:

| Source | Reaction |
| --- | --- |
| Top left | Bottom right |
| Top | Bottom |
| Top right | Bottom left |
| Left | Right |
| Right | Left |
| Bottom left | Top right |
| Bottom | Top |
| Bottom right | Top left |

Cropping retains the opposing vertical anchor, and panning is an adjustment from the chosen anchor. Scaling preserves the same edge/corner. Left/right positions vertically center the reaction rather than retaining its previous top/bottom alignment. Existing sessions derive the new reaction position from their saved source anchor; saved crop, pan and scale are retained.

This changes placement only, not playback or sync. Beta 5 network improvements are retained. The canvas preset list is unchanged; automated geometry checks also exercise 21:9 and 32:9 to prepare for wider canvases.

Please check all eight source positions with the reaction zoom below 100% (so horizontal movement is visible), then try cropping, panning, fullscreen and saving/restoring a session. At full canvas width, left/right anchoring naturally looks the same until the reaction is resized or zoomed.
